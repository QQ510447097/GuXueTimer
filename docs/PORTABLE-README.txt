孤雪凝时（GuXueTimer）
====================

一个 Windows 桌面端的学习计时器：先建计划，再对着计划正计时，
记录自动汇总成柱状图、热力图与成就。运行期完全离线，数据只存在你自己电脑上。

怎么用
------

1. 双击 GuXueTimer.exe
2. 左侧「计划」里建一个计划（比如"英语单词"），它会自动成为当前计划
3. 回到「计时」按开始；结束时点「结束并保存」
4. 「记录」页看本周 / 本月柱状图与当月热力图

点窗口右上角的 × 只是**隐藏到托盘**，计时会继续跑。
要真正退出：右键托盘图标 →「退出」。
不喜欢这个行为，可以在「设置」里关掉「关闭窗口时最小化到托盘」。

第一次运行可能被拦
------------------

Windows 可能弹出「已保护你的电脑」——因为这个程序没有购买代码签名证书。
点「更多信息」→「仍要运行」即可。

如果启动后窗口是空白的，说明系统缺 Microsoft Edge WebView2 运行时
（Win11 自带；Win10 通常随 Edge 一起装好了）。去微软官网装一次即可：
https://developer.microsoft.com/microsoft-edge/webview2/

你的数据在哪
------------

    %LOCALAPPDATA%\GuXueTimer

里面是：

    timer.db         所有记录与设置（标准 SQLite 文件，任何 SQLite 工具都能打开）
    background.png   你在「个性化」里选的背景图（如果选过）
    app.log          运行日志，反馈问题时把它附上

* 备份：复制整个目录
* 换电脑：把整个目录拷过去
* 卸载：删掉这个文件夹和 GuXueTimer.exe 即可（应用不写注册表、不留别的东西）
