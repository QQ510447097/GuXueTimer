# 徽章素材放在这里

每张徽章一个文件，**文件名必须是成就的 id**：

```
frontend/public/badges/<成就的 id>.png
```

（举例：`All` 里定义了一条 `ID: "hours-50"`，就放 `hours-50.png`。）

规格：

- 256 × 256 PNG，透明背景
- 画满整张画布（墙上每格是 44 × 44 的圆角底托，图会铺满它）
- 建议主体居中、四周留一点余量，缩小到 44px 之后边缘不会被切掉
- 墙底下是一张深蓝的冰霜背景图，所以**浅色描边比深色描边安全**；
  55% 透明度的底托会把对比压掉一些，别画得太淡

**没有素材也没关系**：找不到图（或图加载失败）时，会自动回退到内置的矢量奖章，
按稀有度（bronze / silver / gold）上色。所以可以先只加成就定义、之后再补图。

如果图是给浅色主题设计的，深色主题下可能会糊——建议在两种主题下都看一眼
（`tools/shoot.ps1 -Dark` 能直接出一套深色截图）。
