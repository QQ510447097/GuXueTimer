# 徽章素材放在这里

每张徽章一个文件，**文件名必须是成就的 id**：

```
frontend/public/badges/<成就的 id>.png
```

（举例：`All` 里定义了一条 `ID: "hours-50"`，就放 `hours-50.png`。）

规格：

- 256 × 256 PNG，透明背景
- 画满整张画布（卡片里是 30 × 30 的圆角底托，图按 `contain` 缩小放进去）
- 建议主体居中、四周留一点余量，缩到 30px 之后边缘不会被切掉
- 卡片底色是浅蓝的 `--gx-accent-soft`，未解锁时会整体灰度 + 半透明，
  所以**别画得太淡**，否则"解锁了"和"没解锁"看起来一样

**不放图也能用**：找不到图（或加载失败）时会回退到**应用图标**（`brand-mark.png`），
所以可以只写成就定义、之后再慢慢补美术。回退是按 id 缓存的，加载失败不会反复重试。
